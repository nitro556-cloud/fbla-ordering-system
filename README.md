# Rendezvous Cafe

Rendezvous Cafe is a website prototype that aims at providing an easy and efficient process for ordering food online. Users will be able to explore menu items, customize their order as well as move through an easy-to-navigate website. The purpose is to provide an easy ordering process.

This project is developed for the FBLA Introduction to Programming competition using HTML, CSS and JavaScript programming languages. Through this project we will develop our web development skills by developing a functional website for Rendezvous Cafe located in Cumming, Georgia.
